# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability or issue related to the Zavix (ZVX) smart contract or this repository, please report it privately before making the issue public.

Please contact the Zavix team at:

**Email:** info@zavixtoken.com

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the issue, if applicable
- Relevant transaction hashes or contract information
- Any potential impact you identified

Please do not publicly disclose security vulnerabilities before the Zavix team has had an opportunity to review them.
