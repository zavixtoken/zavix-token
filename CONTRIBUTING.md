# Contributing to Zavix

Thank you for your interest in contributing to Zavix (ZVX).

## How to Contribute

If you would like to contribute to the Zavix project:

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes clearly and carefully.
4. Test your changes before submitting them.
5. Open a Pull Request with a clear description of your contribution.

## Code and Documentation

Please keep contributions:

- Clear and easy to understand
- Well documented
- Consistent with the existing project structure
- Free from private keys, passwords, or other sensitive information

## Smart Contract Contributions

The official Zavix smart contract is already deployed on BNB Smart Chain.

Contract:
`0xC162A42B04782Ad6fD1412b87844CeE2b11112fC`

Do not submit changes that claim to modify the deployed contract unless they are clearly identified as separate development work.

## Pull Requests

Please provide a clear explanation of:

- What was changed
- Why the change was made
- Any relevant testing performed

The Zavix team will review contributions before they are accepted.

## Security Issues

For security vulnerabilities, please do not create a public issue.

Instead, follow the instructions in [SECURITY.md](SECURITY.md).
